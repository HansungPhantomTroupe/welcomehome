# 생활권 탐색 프로토타입 (환영여단 · 성북구)

"좋은 동네"가 아니라 **거주 셀 + 주변 셀의 조합**으로 나에게 맞는 생활권을 찾는 서비스의 프로토타입.
페르소나 1(박준호, 한성대) 시나리오를 9단계 위저드로 구현했다.

## 실행

```bash
npm install
cp .env.example .env      # KAKAO_REST_KEY, VITE_KAKAO_JS_KEY 입력
npm run data              # 격자 → 카카오 수집 → 더미 생성 → 셀 분류
npm run dev               # API :4000 + 웹 :5173
```

- 카카오 콘솔 > 플랫폼 > Web 에 `http://localhost:5173` 등록 필요 (JS 키)
- 키가 없으면: 시설은 mock 데이터로 생성되고 지도는 배경 없는 간이 지도로 표시된다 (상단 배지에 `시설: mock` 표시)
- 키를 넣은 뒤 `npm run collect && npm run gen:dummy && npm run build:features` 후 서버 재시작(또는 `POST /api/reload`)

## 데이터 파이프라인 (`server/scripts`)

| 단계 | 스크립트 | 결과 (`data/generated`) |
|---|---|---|
| 격자 | `gen:grid` | 성북구 20개 행정동, 200m×200m 셀 611개 (EPSG:5179 정렬) |
| 시설 수집 | `collect` | 카카오 로컬 API: 음식점·카페·편의점·병원·약국·지하철·마트 + 헬스장(키워드) |
| 더미 생성 | `gen:dummy` | LG U+ 요청서 명세의 유동인구 CSV (약 47만 행) + 더미 매물 |
| 특성/분류 | `build:features` | 셀 특성·유형(`cells.json`), 행정동 통계(`dong_stats.json`) |

### 카카오 API 수집 (`server/src/kakao.ts`)
- 좌표 범위(rect) 검색은 요청당 최대 45건만 노출 → `total_count > 45` 이면 범위를 4분할해 재귀 조회, id로 중복 제거
- 캐시: 요청 단위 디스크 캐시(`data/cache/kakao`, TTL `KAKAO_CACHE_TTL_DAYS`) + rect 결과 메모리 캐시
- 동시 요청 4개 제한, 429/5xx 재시도
- 서버 프록시: `GET /api/places?rect=minLng,minLat,maxLng,maxLat&code=FD6` 또는 `&query=헬스장`

### 더미 유동인구
`셀 × 12개월 × 요일묶음(월~목/금~일) × 시간묶음(08-12/12-16/16-20/20-24) × 성별 × 연령대(20대/30대/40~50대/60대이상)`
컬럼: 기준년월, 요일구분, 시간대, 셀ID, cell_center_x/y, 시도·시군구·행정동 코드/명, 성별, 연령대, 체류/보행/주행인구수.
순수 난수가 아니라 수집한 시설 분포(상권·술집·역·대학)를 숨은 요인으로 시간대·연령 패턴을 만든 뒤 노이즈를 섞었다.
**실제 LG U+ 데이터가 오면 `floating_pop_dummy.csv` 를 같은 컬럼으로 교체하고 `build:features` 만 다시 돌리면 된다.**
(내외국인·국적 컬럼은 페르소나 2용이라 이번 범위에서 제외)

### 셀 유형 분류 (`build:features`)
절대 하한 + 성북구 셀 분위수 기준의 규칙 기반. 우선순위: 야간활동형 → 대학가형 → 의료편의형 → 상업·외식형 → 생활 주거형 → 조용한 주거형. 유동인구·시설이 거의 없는 셀은 녹지·비거주.

## 화면 (`web`)
1. 목적지·행정동 필터 (통학, 20대 활동, 평일 저녁, 주말 야간 과밀)
2. 셀 성격 분류 지도 (유형 / 평일 저녁 / 주말 밤 / 20대 색상 전환)
3. 거주 셀 유형 선택
4. 주변 400~600m 셀 조합 (필요 유형, 음식점·카페 수)
5. 최근접 헬스장 도보 N분
6. 의료 반경 내 진료과 다양성
7. 거주 셀 야간 조용함 vs 주변 셀 저녁 활동
8. 최종 후보 비교 (A/B/C 비교표, 아깝게 탈락한 셀과 사유)
9. 후보 셀 내부 더미 매물 — 매물 좌표 기준으로 헬스장·생활상권·병원 밀집지·통학 재계산

## 프로토타입 한계 / 가정
- 통학 시간: 길찾기 API 없이 `min(도보, 9분 + 거리×1.35 / 300m/분)` 으로 근사
- 도보 시간: 직선거리 × 1.3 / 75m/분
- 셀 유형 임계값은 mock 데이터로 맞춘 값이라, 실제 카카오 데이터 수집 후 분포를 보고 재조정 필요
